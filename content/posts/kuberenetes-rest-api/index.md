The Rest API is the fundamental fabric of K8S. Every communication that happens between components, happens through the API invocations.

> Consequently, everything in the Kubernetes platform is treated as an API object and has a corresponding entry in the [API](https://kubernetes.io/docs/reference/generated/kubernetes-api/v1.18/).
